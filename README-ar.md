# استوديو خطط العمل (Business Plan Studio)

**مرشد تفاعلي لكتابة خطط العمل داخل Claude: أربع مهارات (Agent Skills) تدرّب رواد الأعمال في أي نشاط، بالعربية أو الإنجليزية، من الفكرة الأولى حتى خطة يثق بها البنك أو المستثمر أو الحاضنة أو الجهة المانحة.**

من إعداد **الروابط (AlRawaabit) – وسام زيدان**. مرخّص بموجب رخصة Apache 2.0. الإصدار 2.1.0.

## ماذا يقدّم؟

- **سؤال واحد في كل مرة:** تجيب أنت أولًا، ثم يشرح Claude لماذا يهم هذا الجزء، ويراجع إجابتك، ويقترح صياغة أكثر إحكامًا بكلماتك أنت.
- **يعلّمك أثناء العمل:** 62 درسًا قصيرًا (نقطة التعادل، اقتصاديات الوحدة، حجم السوق، التدفق النقدي، تكلفة اكتساب العميل...) بحسب مستواك.
- **أمثلة عند الحاجة:** إجابات ضعيفة وقوية لكل قسم من شركات خيالية في قطاعات ودول مختلفة، مع أمثلة مكتوبة بالعربية أصلًا لا مترجمة، وحالة عملية كاملة.
- **لأي نشاط:** أسئلة ومؤشرات ونماذج مالية خاصة بعشرة أنواع من الأنشطة: الخدمات، والبرمجيات والاشتراكات، والتجارة الإلكترونية، ومتاجر التجزئة، والمطاعم والمقاهي، والتصنيع، والاستيراد والتصدير والتوزيع، والمنصات، والعيادات والصالونات ومراكز التدريب والرحلات، والمشاريع الاجتماعية.
- **لأي قارئ:** يتغير ترتيب الخطة وتركيزها وطولها بحسب القارئ: حاضنة، أو بنك، أو مستثمر، أو جهة مانحة، أو شريك، أو خطة داخلية.
- **أرقام يمكن الدفاع عنها:** حاسبات مختبرة تتولى كل العمليات الحسابية، ونموذج مالي شهري للتدفق النقدي ونقطة التعادل والسيناريوهات والاحتياج التمويلي (مع تصدير اختياري إلى Excel)، و14 فحصًا للاتساق.
- **أمانة في كل معلومة:** تُصنَّف كل معلومة: مؤكَّد، أو تقدير، أو مخطَّط، أو بحاجة إلى تأكيد. لا يخترع أي رقم، ويوثّق حقائق السوق بمصادر وتواريخ، ويحوّل المسائل الضريبية والقانونية إلى أسئلة لمحاسبك أو محاميك.
- **يحفظ تقدّمك:** ملف صغير باسم plan_state.json يحفظ إجاباتك وأرقامك وافتراضاتك وأسئلتك المفتوحة لتكمل لاحقًا.
- **مخرجات جاهزة:** خطة كاملة بحسب القارئ، وملخص من صفحة، ونموذج العمل التجاري على صفحة واحدة، ومخطط عرض للمستثمرين، وحزمة نصوص جاهزة للصق في نماذج التقديم الإلكترونية.

## المهارات الأربع

| المهارة | الاستخدام |
|---|---|
| business-plan-coach | الرحلة الموجَّهة الكاملة: ابدأ بها |
| business-plan-financials | الأرقام: التسعير، ونقطة التعادل، والتدفق النقدي، والسيناريوهات، والتمويل |
| business-plan-market-research | حجم السوق والمنافسون ومقابلات العملاء والقواعد المحلية، بمصادر موثّقة |
| business-plan-review | مراجعة خطة جاهزة كما يقرؤها مرشد أو بنك أو مستثمر أو جهة مانحة |

## التثبيت

- **Claude.ai:** فعّل تنفيذ الأكواد من الإعدادات، ثم افتح قسم التخصيص (Customize) واختر المهارات (Skills)، وارفع ملفات ZIP الموجودة في مجلد claude-ai-uploads، وابدأ بملف business-plan-coach.zip.
- **Claude Cowork:** افتح ملف business-plan-studio.plugin في محادثة Cowork واقبل الإضافة.
- **Claude Code:** انسخ مجلدات المهارات الأربعة إلى ‎~/.claude/skills‎، أو ثبّتها كإضافة من مستودع GitHub (التفاصيل في README.md).
